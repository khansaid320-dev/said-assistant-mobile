# FINAL V21 — Smart mobile update

This is an additive update of the existing complete mobile publish. It keeps all existing files and functions and adds:

- Stronger natural-language travel parsing: Arlanda/Turkey is kept separate from the home route.
- Travel context uses the saved profile home automatically.
- Flight time is treated as a flight time, not as a request for the current clock time.
- Clear travel answer format with driving time and recommended airport arrival/leave-home time.
- Swedish/English mobile language selector and speech language.
- Direct iPhone app-launch commands for supported apps.
- Native iOS voice integration is documented separately; a PWA cannot provide a system-wide locked-screen wake phrase by itself.
- Existing 33 MOBILE_PUBLISH files are preserved; new modules are additive.
