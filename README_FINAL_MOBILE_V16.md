# Said Assistant 3.0 — Mobile Publisher V16 FINAL SUPER UNIVERSAL

This folder is the complete static mobile publish bundle. Use the entire `MOBILE_PUBLISH` folder together; do not select only the newly added files.

## Included
- Persistent chat history and per-chat deletion
- Durable conversation context and travel slots
- Natural-language query normalization and follow-up understanding
- Multi-source public web research
- Current-news retrieval
- Transport and driving-licence intelligence
- Route/geocoding helpers
- Image OCR and image-question workflow
- Text/PDF attachment reading where the browser supports it
- Local reminders and notifications while the PWA is active
- Voice input and Swedish speech output
- Existing CV, jobs, letter, documents and profile systems

No paid AI API key is required. Web results require internet. Browser/PWA security restrictions mean fully closed-app push notifications and unrestricted private APIs cannot be guaranteed without a backend service.
